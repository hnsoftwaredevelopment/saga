# Milestone 44: bulk tags opschonen

Testbuild: `Builds\Debug\Saga.exe`, versie `2026.10.22.15` (22 oktober 2026, 10:08).

## Voorbereiding

- [x] Maak zo nodig een bibliotheekback-up.
- [x] Kies twee of meer boeken met verschillende rommelige tags, bijvoorbeeld ` Thriller ` en `Historie, Reizen`.
- [x] Noteer hun oorspronkelijke tags en enkele andere metadatavelden.

## Voorstel en annuleren

- [x] Open Quality, kies Rommelige tags en selecteer meerdere boeken met Ctrl of Shift.
- [x] Tags opschonen is beschikbaar en opent een overzicht met het juiste aantal boeken.
- [x] Per boek staan titel, huidige tags en de eigen opgeschoonde tags naast elkaar.
- [x] Een leeg resultaat meldt Geen tags. Er worden geen tags tussen boeken uitgewisseld.
- [x] Scroll met muis en toetsenbord door het overzicht; lange titels en tags lopen netjes om.
- [x] Annuleer met de knop en met Escape. Er is niets opgeslagen.

## Bevestigen en verversen

- [x] Open opnieuw en bevestig via de knop met het aantal boeken of met Enter.
- [x] Bij volledig succes verschijnt alleen een korte groene melding met het aantal gewijzigde boeken.
- [x] De herstelde regels verdwijnen uit Rommelige tags; telling en selectie worden bijgewerkt.
- [x] Controleer in het hoofdscherm dat ieder boek zijn eigen opgeschoonde tags heeft en de tagfilters actueel zijn.
- [x] Andere metadata, omslagen, bestanden en leesstatus zijn behouden.
- [x] Heropen Saga en controleer dat de tags opgeslagen blijven.

## Enkelvoudig en regressies

- [x] Eén geselecteerd boek toont nog het bestaande bewerkvenster waarin het voorstel gewijzigd kan worden.
- [x] Controleer dat bulk auteur, taal, serie en Dit is correct herkenbaar blijven werken.
- [x] Controleer zo mogelijk een andere interfacetaal en een kleiner venster.

## Fouten en gewijzigde gegevens

- [x] Indien veilig reproduceerbaar: een inmiddels aangepast of verwijderd boek wordt niet vanuit oude gegevens overschreven; andere boeken worden wel verwerkt.
- [x] Gemengde resultaten geven aantallen in een rode melding; mislukte boeken blijven geselecteerd en kunnen opnieuw geprobeerd worden.

Fouten, annulering tijdens verwerking, gewijzigde tags en gemengde resultaten zijn automatisch getest. Markeer handmatig niet reproduceerbare controles als niet uitgevoerd; veroorzaak hiervoor geen schade aan de echte bibliotheek.
