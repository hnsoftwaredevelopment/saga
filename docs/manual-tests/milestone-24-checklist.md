# Milestone 24 - Tagacties In Metadata Edit

Gebruik deze checklist voor de metadata cleanup-slice waarmee tags in bulk kunnen worden vervangen, toegevoegd en verwijderd.

## Voorbereiding

- [ ] Selecteer meerdere boeken met verschillende bestaande tags.
- [ ] Open Metadata in meerdere boeken bewerken via de toolbar of het contextmenu.
- [ ] Controleer dat bij Tags een actie beschikbaar is: Vervangen, Toevoegen en Verwijderen.

## Vervangen

- [ ] Vink Tags aan.
- [ ] Kies Vervangen.
- [ ] Vul meerdere tags in, gescheiden met puntkomma's.
- [ ] Sla op.
- [ ] Controleer dat de bestaande tags van de geselecteerde boeken zijn vervangen door de nieuwe tags.

## Toevoegen

- [ ] Selecteer opnieuw meerdere boeken met bestaande tags.
- [ ] Kies Toevoegen.
- [ ] Vul een of meer nieuwe tags in.
- [ ] Sla op.
- [ ] Controleer dat bestaande tags blijven staan en de nieuwe tags zijn toegevoegd.
- [ ] Controleer dat dubbele tags niet dubbel worden opgeslagen.

## Verwijderen

- [ ] Selecteer meerdere boeken waarvan minstens een deel dezelfde tag heeft.
- [ ] Kies Verwijderen.
- [ ] Vul de te verwijderen tag(s) in.
- [ ] Sla op.
- [ ] Controleer dat alleen deze tags zijn verwijderd.
- [ ] Controleer dat andere tags blijven staan.

## Refresh

- [ ] Controleer dat de tagkolom direct is bijgewerkt.
- [ ] Controleer dat het tagfilter links direct de nieuwe aantallen toont.
- [ ] Controleer dat zoeken direct werkt op de aangepaste tags.
- [ ] Controleer dat het details pane van een geselecteerd boek direct de aangepaste tags toont.
