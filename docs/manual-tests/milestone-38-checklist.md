# Milestone 38 handmatige checklist

## Voorbereiding

- [X] Start de actuele Debug-versie van `Builds\Debug\Saga.exe`.
- [X] Open een bibliotheek met een kwaliteitscategorie waarin meerdere boeken staan.
- [X] Open het kwaliteitsscherm en kies die categorie.

## Meerdere boeken selecteren

- [X] Selecteer met `Ctrl` enkele niet-aaneengesloten boeken.
- [X] Selecteer met `Shift` een aaneengesloten reeks boeken.
- [X] Controleer dat `Dit is correct` beschikbaar blijft bij meerdere geselecteerde boeken.
- [X] Controleer dat `Openen in bibliotheek` en de herstelknop niet beschikbaar zijn zolang meerdere boeken geselecteerd zijn.
- [X] Controleer dat dezelfde selectie ook met het toetsenbord kan worden gemaakt.

## Annuleren en bevestigen

- [X] Kies `Dit is correct` met twee of meer boeken geselecteerd.
- [X] Controleer dat de bevestiging het juiste aantal geselecteerde boeken noemt.
- [X] Kies eerst `Nee` en controleer dat geen enkele geselecteerde regel verdwijnt.
- [X] Herhaal de actie, kies `Ja` en controleer dat precies de geselecteerde regels verdwijnen.
- [X] Controleer dat niet-geselecteerde regels en andere kwaliteitsmeldingen voor dezelfde boeken blijven staan.
- [X] Controleer dat Saga na de actie een logische volgende regel selecteert, of de selectie wist wanneer de categorie leeg is.

## Enkelvoudig gedrag

- [X] Selecteer één boek en kies `Dit is correct`.
- [X] Controleer dat hierbij geen extra bevestiging verschijnt.
- [X] Controleer dat `Openen in bibliotheek` en de passende herstelactie bij één boek nog normaal werken.

## Herstellen vanuit Instellingen

- [X] Open Instellingen en ga naar het tabblad `Kwaliteit`.
- [X] Controleer dat de zojuist genegeerde kwaliteitsmeldingen daar zichtbaar zijn.
- [X] Herstel enkele geselecteerde meldingen.
- [X] Open het kwaliteitsscherm opnieuw en controleer dat de herstelde meldingen terugkomen wanneer het probleem nog bestaat.

## Talen en foutafhandeling

- [X] Schakel Saga naar een andere taal en controleer dat de bulkbevestiging volledig vertaald is.
- [X] Indien een opslagfout veilig kan worden nagebootst: controleer dat geen enkele geselecteerde regel verdwijnt en dat Saga een duidelijke foutmelding toont.

## Resultaat

- [X] Alle bovenstaande controles zijn geslaagd, of afwijkingen zijn met de exacte stappen genoteerd.

Handmatig geaccepteerd op 1 oktober 2026 met Saga 2026.10.1.54.
