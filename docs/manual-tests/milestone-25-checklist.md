# Milestone 25 - Custom Metadata Filterwaarden Opschonen

Gebruik deze checklist voor de slice waarmee custom metadata waarden direct vanuit de filterlijst kunnen worden opgeschoond.

## Voorbereiding

- [ ] Maak of gebruik een custom metadata veld van type Tekst, Enkele keuze of Meerdere keuze.
- [ ] Vul dit veld bij meerdere boeken met verschillende waarden.
- [ ] Open de filterlijst links en klap het custom metadata filter open.

## Hernoemen

- [ ] Klik met rechts op een waarde in een custom metadata filter.
- [ ] Kies Hernoemen.
- [ ] Geef een nieuwe waarde op.
- [ ] Controleer dat de filterlijst direct de nieuwe waarde toont.
- [ ] Controleer dat de betrokken boeken direct de nieuwe waarde tonen in Details en kolommen.

## Meerdere Keuze

- [ ] Gebruik een custom metadata veld van type Meerdere keuze met bijvoorbeeld `Thriller; Fantasy`.
- [ ] Hernoem alleen `Thriller`.
- [ ] Controleer dat `Fantasy` behouden blijft.
- [ ] Controleer dat de filters per losse waarde blijven werken.

## Verwijderen

- [ ] Klik met rechts op een waarde in een custom metadata filter.
- [ ] Kies Verwijderen en bevestig.
- [ ] Controleer dat alleen deze waarde is verwijderd.
- [ ] Controleer dat andere waarden bij hetzelfde boek blijven staan.
- [ ] Controleer dat boeken zonder resterende waarde geen lege custom metadata waarde tonen.

## Niet-Bewerkbare Typen

- [ ] Controleer dat nummer-, datum- en ja/nee-custom metadata filters geen opschoonactie nodig hebben voor deze slice.
- [ ] Controleer dat nummer-, datum- en ja/nee-custom metadata filters geen menu-item Hernoemen tonen.
- [ ] Controleer dat nummer-, datum- en ja/nee-custom metadata filters geen menu-item Verwijderen tonen.
