# Filterlijst zoeken

## Doel

Lange filterlijsten moeten snel doorzoekbaar zijn zonder de actieve bibliotheekselectie te veranderen. Dit is vooral belangrijk voor grote bibliotheken met duizenden auteurs, series, tags of custom metadatawaarden.

## Eerste slice

- Voeg per lange filtergroep een zoekveld toe.
- Ondersteun zoeken in:
  - Auteurs
  - Series
  - Tags
  - Taal
  - Type
  - Custom metadata filters
- Toon per filtergroep hoeveel items zichtbaar zijn ten opzichte van het totaal.
- Verberg niet-matchende filteritems visueel, maar behoud bestaande selecties.
- Laat het filteren van de boekenlijst ongewijzigd: alleen geselecteerde checkboxen bepalen welke boeken zichtbaar zijn.
- Toon de zoekrij alleen bij langere filterlijsten of wanneer er al zoektekst actief is.
- Gebruik een compact zoekveld zodat het filterpaneel rustig blijft.

## Later

- Watermark/placeholder tekst in de zoekvelden zelf.
- Keyboard shortcuts voor focus op filterzoekvelden.
